# templates/me — ejemplos para arrancar

Copiá esta carpeta a `me/` y cambiá cada archivo por lo tuyo:

```bash
cp -r templates/me me
```

| Archivo | Qué es |
|---|---|
| `settings.toml` | Ubicación, idiomas, roles prioritarios, piso de %, día del reporte |
| `keywords.txt` | Palabras del título que te interesan (tu rubro) |
| `skills.txt` | Tus skills: suman al % de match |
| `tech.txt` | Vocabulario de requisitos de tu área: lo que pidan y no esté en skills.txt cuenta como gap |
| `empresas.txt` | Portales de empresas a seguir (opcional) |

Tu repo tiene que ser **privado** (creado con "Use this template", no con fork):
`me/` se sube al repo para que GitHub Actions lo lea.
